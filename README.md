## Commit コメントルール
下記のルールに基づいてコメントしています。

```
👍 ファイル追加  
✨ ファイル更新  
🧹 ファイル削除  
🚚 ファイル移動・ファイル名変更 
🎨 スタイル追加・変更　
🛠️ 設定追加・変更
```
